## 6. Mapping DX11 → UE5.8

- Resource binding: cbuffer slots → `BEGIN_SHADER_PARAMETER_STRUCT` 1:1 named uniforms;
  T/MS textures → RDG SRVs; output → RDG UAV; `TStaticSamplerState<SF_Bilinear…Clamp>`.
- Coordinates: bake runs in the PLANET-LOCAL frame (sun/up converted once on CPU/GT);
  UE world handedness never enters the math. Camera-relative km snapshot feeds RT;
  no absolute-km floats in-shader (large-planet safe, proven by Case G).
- Texel (x,y) ↔ uv ((x+0.5)/W,(y+0.5)/H), same as reference `pixPos/(W,H)`; generation and
  future sampling share the convention (self-consistent; DX11 byte-compare would need a
  row-flip allowance, not math changes).
- Format 32F kept; resolutions centralized in `HillaireLimits.h`.

## 8. Cache / invalidation

- Per-planet slots (never global): T key = profile hash; MS key = hash(profile, factor);
  SkyView predicate (Phase-1 `QueryRegen`, unchanged) = profile hash + slot-0 sun-dir
  cache (>~0.001 rad) + slot-0 identity + height eps + `bFastSkyEnabled`.
- Phase-2B completion: SkyView rebuilds when MS regenerates underneath it in the same call
  (MS values bake into the march — otherwise stale), when pooled is missing, or via
  `ShouldRebuildSkyView` (pure, unit-tested). Zero lights → SkyView skipped (no sun).
- Underground cameras clamp to the 20 m floor (spec precision rule) keeping keys stable.
- Secondary-light motion never invalidates SkyView (primary-baked, tested).
